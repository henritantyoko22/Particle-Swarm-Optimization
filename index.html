⚙ Konsep & Rumus Matematis PSO untuk Mahasiswa

Dalam Particle Swarm Optimization (PSO), setiap kandidat solusi disebut partikel. Untuk kasus tuning SVM ini:

Posisi partikel: X = [C, γ]
Fungsi Objektif: Loss = 1 - F1_Score(X_train, y_train, cv=5)

1. Rumus Pembaruan Kecepatan (Velocity Update):

v[i](t+1) = w · v[i](t) + c1 · r1 · (pBest[i] - X[i](t)) + c2 · r2 · (gBest - X[i](t))
  • Komponen Inersia (w): Menjaga momentum partikel dari iterasi sebelumnya agar tidak mudah terjebak di local optimum.
  • Komponen Kognitif (c1): Tarikan ke posisi terbaik yang pernah dikunjungi partikel itu sendiri (pBest).
  • Komponen Sosial (c2): Tarikan ke posisi terbaik dari seluruh kawanan kawanan (gBest).
  • r1, r2: Bilangan acak seragam [0, 1] yang memberikan efek eksplorasi stokhastik.

2. Rumus Pembaruan Posisi (Position Update):

X[i](t+1) = X[i](t) + v[i](t+1)

Jika posisi baru melebihi batas [bounds_min, bounds_max], posisi akan dipotong (clamped) agar tetap dalam ruang pencarian yang valid.

Tip Dosen/Mahasiswa: Cobalah ubah nilai w menjadi tinggi (> 1.0) untuk melihat partikel menyebar keluar ruang, atau ubah c2 tinggi untuk melihat partikel berkumpul sangat cepat ke satu titik!

💡 Mengapa SVM dan PSO Sangat Membutuhkan Penanganan Outlier?
  • Standarisasi (StandardScaler): Karena rentang nilai fitur berbeda sangat jauh (Total SO2 skala ratusan vs Chlorides nol koma), standarisasi z-score wajib dilakukan agar outlier tidak mendistorsi perhitungan jarak kernel RBF.
  • Peran Parameter C pada SVM: Nilai C adalah penalti kesalahan klasifikasi (*soft margin*). Jika C terlalu besar, model memaksakan margin memisahkan seluruh outlier (rawan *overfitting*). Algoritma PSO bertugas mencari kompromi nilai C dan Gamma terbaik agar model toleran terhadap outlier tanpa mengorbankan akurasi.
